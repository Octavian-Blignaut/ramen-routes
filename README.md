## 📖 プロローグ // Prologue

You are not just eating noodles. You are on a **quest**. Every bowl of ramen, pho,
khao soi, tagliatelle, udon, or pad thai is a checkpoint on your journey across the
world map. This is your **passport**. Stamp it wisely, traveler. 🗺️✨

## ⚔️ Character Sheet // Features

| Stat | Skill |
|---|---|
| 🗺️ **Explorer** | Interactive Leaflet.js world map with hand-drawn-style noodle pins |
| 📸 **Chronicler** | Log restaurant, noodle type, photo, and slurp scale (1–5 ⭐) |
| 🎴 **Collector** | Every visit becomes a stylized "Passport Stamp" card |
| 🏆 **Achiever** | Auto-unlocking badges — *Ramen Rookie*, *Global Slurper*, and more |
| 💾 **Persistent** | LocalStorage save file — your quest never resets on refresh |
| 🎨 **Aesthetic** | Vibrant CSS-variable theme, FontAwesome icons, zero build tools |

---

## 🎮 How to Play

```bash
# Clone the dojo
git clone https://github.com/Octavian-Blignaut/ramen-routes.git
cd ramen-routes

# Begin your training (no installs, no build step)
open index.html
```

Or deploy straight to **GitHub Pages** — it's a single self-contained `index.html`.
No frameworks. No build pipeline. Just you, noodles, and destiny. 🌸
